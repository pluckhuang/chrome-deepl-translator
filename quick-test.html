🌐 DeepL 翻译插件 - 快速测试页面

📝 测试步骤：

  1. 确保插件已重新加载（chrome://extensions/ → 刷新）
  2. 按 F12 打开开发者工具，切换到 Console 标签
  3. 在下面的文本框中选中一段文本
  4. 观察 Console 输出和页面效果
  5. 点击出现的 🌐 翻译 按钮
  6. 查看翻译结果

⚠️ 提醒：

  • 必须先设置 DeepL API Key（点击插件图标 → 输入 → 保存）
  • 必须在 Console 中看到 "DeepL 翻译插件内容脚本已加载"
  • 如果代理配置不正确，翻译会失败

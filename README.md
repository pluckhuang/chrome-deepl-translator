# DeepL 段落翻译 Chrome 插件

这是一个使用 DeepL API 进行文本翻译的 Chrome 浏览器扩展。

## 功能特点

- ✨ 支持多种语言互译
- 🎯 选中文本即可快速翻译
- 💾 自动保存 API Key
- 🎨 美观的用户界面
- 🚀 快速响应，体验流畅
- 📋 右键菜单快速翻译
- 📖 全文双语翻译，原文与中文译文同时展示，支持恢复原文
- 📸 在 X/Twitter 里右键保存帖子截图

## 安装步骤

### 1. 获取 DeepL API Key

1. 访问 [DeepL API 官网](https://www.deepl.com/pro-api)
2. 注册账号（免费版每月有 50 万字符的免费额度）
3. 在控制台获取你的 API Key

### 2. 安装插件

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 打开右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `chrome-deepl-translator` 文件夹
6. 插件安装完成！

### 3. 配置 API Key

1. 点击浏览器工具栏的插件图标
2. 在弹出窗口中输入你的 DeepL API Key
3. 点击「保存 API Key」按钮

## 使用方法

### 方法 1: 弹窗翻译
1. 点击插件图标打开弹窗
2. 在文本框中输入要翻译的内容
3. 选择源语言和目标语言
4. 点击「翻译」按钮

**💡 小技巧**：如果在打开弹窗前选中了网页上的文本，该文本会自动填充到输入框中！

### 方法 2: 选中文本翻译
1. 在任意网页选中文本
2. 会自动出现「🌐 翻译」按钮
3. 点击按钮即可查看翻译结果

### 方法 3: 右键菜单翻译
1. 选中网页上的文本
2. 右键点击，选择「使用 DeepL 翻译」
3. 查看翻译结果

### 方法 4: 全文翻译与双语对照
1. 在网页空白处右键
2. 选择「全文双语翻译（保留原文）」，中文译文会显示在对应原文段落下方
3. 选择「翻译整个网页」，仍可直接用中文替换网页文字
4. 选择「恢复网页原文」，移除双语译文或撤销全文替换；翻译中也可恢复，停止后续写入

双语模式会合并段落内的链接、加粗等行内文字，保留原文排版与交互。隐藏内容、代码和输入框不会翻译。重复执行会复用当前页面的翻译缓存，避免叠加译文。此功能处理执行时已加载的页面文字，新加载的内容可再次右键翻译。

更新插件后，请在 `chrome://extensions/` 中重新加载插件，并刷新要翻译的网页。

### 方法 5: X 帖子截图保存
1. 打开 `x.com` 或 `twitter.com`
2. 把鼠标移到目标帖子内容区域内并右键
3. 选择「保存当前帖子截图」
4. 等待浏览器弹出保存位置，保存 PNG 截图

## 项目结构

```
chrome-deepl-translator/
├── manifest.json              # 注入顺序与权限
├── background.js              # 消息路由、截图与下载
├── content.js                 # 通用网页消息入口
├── twitter_translator.js      # X 帖子增量监听与翻译界面
├── popup.html / .css / .js     # 弹窗输入、设置与结果
├── content.css                # 插件页面组件样式
├── src/
│   ├── shared/                # 有界缓存、Key清理、统一消息客户端
│   ├── background/            # DeepL服务：分批、去重、缓存、并发与超时
│   └── content/               # 划词、全文任务、DOM渲染、提示、X截图
├── tests/                     # 后台单元测试与真实浏览器回归
└── icons/
```

所有翻译入口统一通过后台调用 DeepL，内容脚本无需读取 API Key。后台按原文、语言和账户合并重复请求，限制最多两个并发请求，并按条数和 UTF-8 字节数分批。请求有超时，失败结果不缓存；前端关闭或恢复原文后会丢弃迟到结果。缓存只存于内存且有容量上限。

仍然无需构建：直接加载仓库目录即可。`manifest.json` 中公共脚本先于功能模块注入，各功能通过 `DeepL` 命名空间公开少量入口，内部状态不共享全局变量。


## 注意事项

1. **API Key 安全**: 请妥善保管你的 API Key，不要分享给他人
2. **免费额度**: DeepL 免费版每月有 50 万字符限制
3. **网络要求**: 需要能够访问 DeepL API
   - 如果所在网络无法直接访问 DeepL，请检查浏览器与系统代理设置
   - 如果遇到网络错误，请检查代理设置
4. **文本长度**: 单次翻译建议不超过 5000 字符

## 开发建议

开发测试需要 Node.js 22 或更高版本及本机 Chrome，无需安装 npm 依赖。

```bash
npm test
npm run test:browser
```

浏览器测试使用临时用户目录，模拟 DeepL 响应、截图和下载，不读取现有浏览器资料，也不消耗翻译额度。覆盖弹窗、划词、全文替换、双语对照、X 动态内容、长帖拼接和失败恢复。Chrome 不在默认位置时可用 `CHROME_PATH` 指定可执行文件。

`quick-test.html` 用于加载扩展后的手动检查；`tests/full-page-translation.html` 也可独立打开执行全文 DOM 回归。

## 常见问题

**Q: 提示"API Key 无效"怎么办？**
A: 请检查 API Key 是否正确复制，确保没有多余的空格。

**Q: 翻译失败怎么办？**
A: 检查网络连接，确保能访问 DeepL API。免费版 API 地址为 `api-free.deepl.com`。

**Q: 如何切换免费版和付费版？**
A: 插件会自动检测（免费版 API Key 以 `:fx` 结尾）。

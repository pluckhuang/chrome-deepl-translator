# DeepL 段落翻译 Chrome 插件

这是一个使用 DeepL API、本地模型（Ollama / LM Studio）或 OpenRouter 在线模型进行文本翻译的 Chrome 浏览器扩展，支持划词与全文双语翻译，也可以保存 X 帖子截图和整页长截图。

## 功能特点

- ✨ 支持多种语言互译
- 🎯 选中文本即可快速翻译
- 💾 自动保存 API Key
- 🎨 美观的用户界面
- 🚀 快速响应，体验流畅
- 📋 右键菜单快速翻译
- 📖 全文双语翻译，原文与中文译文同时展示，支持恢复原文
- 🖥️ 可切换为本地模型（Ollama / LM Studio）或 OpenRouter 在线模型翻译，DeepL 额度用完时手动切换
- 📸 在 X/Twitter 里右键保存帖子截图
- 🖼️ 整页截图：自动滚动拼接，保存从上到下的完整网页

## 安装步骤

### 1. 获取 DeepL API Key

1. 访问 [DeepL API 官网](https://www.deepl.com/pro-api)
2. 注册账号（免费版每月有 50 万字符的免费额度）
3. 在控制台获取你的 API Key

### 2. 安装插件

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 打开右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `chrome-deepl-translator` 文件夹
6. 插件安装完成！

### 3. 配置 API Key

1. 点击浏览器工具栏的插件图标
2. 在弹出窗口中输入你的 DeepL API Key
3. 点击「保存 API Key」按钮

## 使用方法

### 方法 1: 弹窗翻译
1. 点击插件图标打开弹窗
2. 在文本框中输入要翻译的内容
3. 选择源语言和目标语言
4. 点击「翻译」按钮

**💡 小技巧**：如果在打开弹窗前选中了网页上的文本，该文本会自动填充到输入框中！

### 方法 2: 选中文本翻译
1. 在任意网页选中文本
2. 会自动出现「🌐 翻译」按钮
3. 点击按钮即可查看翻译结果

### 方法 3: 右键菜单翻译
1. 选中网页上的文本
2. 右键点击，选择「使用 DeepL 翻译」
3. 查看翻译结果

### 方法 4: 全文翻译与双语对照
1. 在网页空白处右键
2. 选择「全文双语翻译（保留原文）」，中文译文会显示在对应原文段落下方
3. 选择「翻译整个网页」，仍可直接用中文替换网页文字
4. 选择「恢复网页原文」，移除双语译文或撤销全文替换；翻译中也可恢复，停止后续写入

双语模式会合并段落内的链接、加粗等行内文字，保留原文排版与交互。隐藏内容、代码和输入框不会翻译。重复执行会复用当前页面的翻译缓存，避免叠加译文。此功能处理执行时已加载的页面文字，新加载的内容可再次右键翻译。

更新插件后，请在 `chrome://extensions/` 中重新加载插件，并刷新要翻译的网页。

### 方法 5: X 帖子截图保存
1. 打开 `x.com` 或 `twitter.com`
2. 把鼠标移到目标帖子内容区域内并右键
3. 选择「保存当前帖子截图」
4. 等待浏览器弹出保存位置，保存 PNG 截图

### 方法 6: 整页截图
1. 在网页空白处右键，选择「保存整个网页截图」；或点击插件图标，点「📸 保存整页截图」
2. 页面会先自动滚动一遍加载懒加载图片，再逐屏截取，工具栏图标上显示进度；期间请不要滚动或切换标签页
3. 完成后浏览器弹出保存位置，保存 PNG 截图，页面回到原来的滚动位置

固定顶栏只出现在截图顶部，Cookie 横幅、客服按钮等底部浮层只出现在底部，吸顶元素保留在原本位置，不会每屏重复。页面本身不滚动、内容在内部滚动区域里的单页应用，会截取面积最大的滚动区域。截图按当前窗口宽度生成；超长页面会先降到 1 倍分辨率，仍超过 32000px 时只保留前 32000px 并提示。浏览器内部页面（如 `chrome://`、扩展商店）无法截图。

### 方法 7: 使用本地模型翻译

DeepL 额度用完时会提示「可在插件弹窗将翻译引擎切换为本地模型」。插件**不会自动切换**，需要手动操作：

1. 安装 [Ollama](https://ollama.com/download)（或 `brew install --cask ollama`），打开一次
2. 在项目目录运行安装脚本（macOS），一条命令装好模型、提速设置和开机自启：
   ```bash
   scripts/setup-local-model.sh
   ```
3. 在 `chrome://extensions/` 重新加载插件，点击插件图标，把「翻译引擎」切换为「本地模型」。服务地址和模型名称已填好默认值，点「测试连接」确认能出译文
4. 之后划词、全文双语、X 帖子和弹窗翻译都会使用本地模型；切回 DeepL 同样在弹窗里操作

**安装脚本做了什么**（可重复运行，已完成的步骤会跳过）：

- **下载模型**：[Hunyuan-MT-7B](https://huggingface.co/tencent/Hunyuan-MT-7B) 的 Q5_K_M 量化版（约 5.4GB）。先测速，自动选 Hugging Face 或国内镜像 hf-mirror.com，支持断点续传；校验 SHA-256 后以 `hf.co/mradermacher/Hunyuan-MT-7B-GGUF:Q5_K_M` 导入 Ollama，与 `ollama pull` 的结果相同
- **提速设置**：按内存设置 Ollama 同时处理的段数（24GB 及以上 4 段，16GB 2 段，更小 1 段），模型空闲 15 分钟后卸载。实测 M5 / 24GB 上 8 段从 10.7 秒降到 6.3 秒，模型占用内存从 6.3GB 增至 8.9GB
- **开机自启**：安装 LaunchAgent（`~/Library/LaunchAgents/local.chrome-deepl-translator.ollama-env.plist`），每次登录时运行 `~/.ollama/ollama-env.sh` 设置上述变量；Ollama 未运行就启动它，先于设置启动了就重启一次，日志在 `~/.ollama/logs/ollama-env.log`
- **试翻译**：确认 Ollama 已按新设置运行并能出译文

| 参数 | 说明 |
|---|---|
| `--parallel 1-8` | 同时处理的段数，默认按内存决定 |
| `--keep-alive 15m` | 空闲多久后卸载模型，如 `1h`、`0`（用完即卸载）、`-1`（一直常驻） |
| `--mirror` / `--no-mirror` | 强制使用镜像 / 只用 Hugging Face，默认自动测速选择 |
| `--uninstall` | 撤销提速设置和开机自启，恢复 Ollama 默认设置（保留模型，删除用 `ollama rm`） |

不用脚本也可以手动安装：`ollama pull hf.co/mradermacher/Hunyuan-MT-7B-GGUF:Q5_K_M`。这样没有提速设置，国内网络也可能拉取很慢。

**使用说明**：

- **其他模型**：也可以填其他模型。插件按模型名选提示词：Hunyuan-MT 用官方简短模板；Hy-MT2 系列（如 `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M`）用官方「个性化」模板，附上忠实、去翻译腔、语气随原文等编号要求；其他通用模型（如 Qwen3 的非思考版）用同样要求的系统提示，并去掉模型输出的思考内容。使用 LM Studio 时把服务地址改为 `http://127.0.0.1:1234/v1`
- **不需要配置 `OLLAMA_ORIGINS`**：插件只对自己发往 `127.0.0.1` / `localhost` 的请求去掉 Origin 请求头，网页对本机服务的请求不受影响。若把 Ollama 放在其他机器上，需在那台机器上设置 `OLLAMA_ORIGINS="chrome-extension://*"`
- **首次调用较慢**：Ollama 加载模型需要 5–10 秒，之后单句一般在一秒左右
- **全文翻译较慢**：本地模型逐段生成，插件同时发 4 个请求、每 8 段更新一次进度，并先翻译屏幕内的段落；长页面仍需几十秒到几分钟，翻译中可随时「恢复网页原文」
- **译文分开缓存**：切换引擎或模型后重新翻译，不会显示另一个引擎的旧译文
- **去掉多余的括号说明**：Hunyuan-MT 常给习语补一段括号解释（如「细节决定成败（或：魔鬼藏在细节之中）」），原文没有括号时插件会去掉译文里的括号内容；原文本身有括号则原样保留
- **内存**：模型加载期间占 6–9GB；16GB 内存建议 `--parallel 2`，8GB 内存不建议使用本地模型

### 方法 8: 使用 OpenRouter 在线模型

[OpenRouter](https://openrouter.ai) 用一个 API Key 调用各家模型，按用量付费。同样只能手动切换，余额不足时会提示充值或切换引擎，不会自动改用其他引擎。

1. 在 [openrouter.ai/keys](https://openrouter.ai/keys) 创建 API Key 并充值
2. 点击插件图标，把「翻译引擎」切换为「OpenRouter（在线模型）」，填入 API Key，模型名称可从下拉建议里选，也可以填任意 OpenRouter 模型名
3. 点「测试连接」：显示译文、耗时和这次请求的花费；满意后点「保存设置」
4. 在弹窗里翻译时，译文下方会注明引擎、模型和耗时，方便对比不同模型

| 模型 | 类型 | 价格（每百万 token，输入 / 输出） | 每 1000 个英文单词约 |
|---|---|---|---|
| `tencent/hy-mt2-30b-a3b`（默认） | 腾讯翻译专用旗舰 | $0.07 / $0.30 | $0.001 |
| `qwen/qwen3.8-flash` | 通用，中文强 | $0.15 / $0.47 | $0.002 |
| `anthropic/claude-haiku-5.5` | 通用，听指令 | $0.10 / $0.50 | $0.002 |
| `openai/gpt-6-luna` | 通用 | $0.10 / $0.50 | $0.002 |
| `qwen/qwen3.8-max-0902` | 通用旗舰 | $2 / $6 | $0.02 |

价格为 2026 年 10 月 OpenRouter 的数据，以 [OpenRouter 模型页](https://openrouter.ai/models) 为准；每千词的花费是粗略估算。

- **提示词**：和本地模型的规则相同，按模型名自动选择
- **通用模型的思考**：插件把思考力度调到最低，且不返回思考内容；思考仍按输出计费，所以通用模型实际花费会略高于表中估算
- **并发**：同时发 6 个请求，全文翻译每 8 段更新一次进度
- **隐私**：文字会发送到 OpenRouter 和对应的模型服务商；只有本地模型能让文字不离开电脑
- **缓存**：按模型区分，换模型后重新翻译不会显示旧译文

## 项目结构

```
chrome-deepl-translator/
├── manifest.json              # 注入顺序与权限
├── background.js              # 消息路由、截图与下载、整页截图入口
├── content.js                 # 通用网页消息入口
├── twitter_translator.js      # X 帖子增量监听与翻译界面
├── popup.html / .css / .js     # 弹窗输入、设置与结果
├── content.css                # 插件页面组件样式
├── src/
│   ├── shared/                # 有界缓存、Key清理、统一消息客户端
│   ├── background/            # 翻译服务（DeepL / 本地模型 / OpenRouter）：分批、去重、缓存、并发与超时；整页截图拼接
│   └── content/               # 划词、全文任务、DOM渲染、提示、X截图、整页截图滚动
├── scripts/                   # 本地模型安装脚本（Ollama、模型、提速与开机自启）
├── tests/                     # 后台单元测试与真实浏览器回归
└── icons/
```

所有翻译入口统一通过后台调用弹窗里选定的翻译引擎，内容脚本无需读取 API Key，也不能自行指定引擎。DeepL 按原文、语言和账户合并重复请求，限制最多两个并发请求，并按条数和 UTF-8 字节数分批；本地模型和 OpenRouter 逐段请求（分别 4 路和 6 路并发），缓存按地址和模型区分。请求有超时，失败结果不缓存；前端关闭或恢复原文后会丢弃迟到结果。缓存只存于内存且有容量上限。

仍然无需构建：直接加载仓库目录即可。`manifest.json` 中公共脚本先于功能模块注入，各功能通过 `DeepL` 命名空间公开少量入口，内部状态不共享全局变量。


## 注意事项

1. **API Key 安全**: 请妥善保管你的 API Key，不要分享给他人
2. **免费额度**: DeepL 免费版每月有 50 万字符限制
3. **网络要求**: 需要能够访问 DeepL API
   - 如果所在网络无法直接访问 DeepL，请检查浏览器与系统代理设置
   - 如果遇到网络错误，请检查代理设置
4. **文本长度**: 单次翻译建议不超过 5000 字符

## 开发建议

开发测试需要 Node.js 22 或更高版本及本机 Chrome，无需安装 npm 依赖。

```bash
npm test
npm run test:browser
```

浏览器测试使用临时用户目录，模拟 DeepL 响应、截图和下载，不读取现有浏览器资料，也不消耗翻译额度。覆盖弹窗、翻译引擎切换、划词、全文替换、双语对照、X 动态内容、长帖拼接、整页截图逐屏拼接与浮层处理和失败恢复。Chrome 不在默认位置时可用 `CHROME_PATH` 指定可执行文件。

`quick-test.html` 用于加载扩展后的手动检查；`tests/full-page-translation.html` 也可独立打开执行全文 DOM 回归。

## 常见问题

**Q: 提示"API Key 无效"怎么办？**
A: 请检查 API Key 是否正确复制，确保没有多余的空格。

**Q: 翻译失败怎么办？**
A: 检查网络连接，确保能访问 DeepL API。免费版 API 地址为 `api-free.deepl.com`。

**Q: 如何切换免费版和付费版？**
A: 插件会自动检测（免费版 API Key 以 `:fx` 结尾）。
